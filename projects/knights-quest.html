About the Project

Building a Fantasy Adventure

Knight's Quest: Rescue the Princess is a 2D platformer developed with Unity. The player controls a knight who must navigate platforms, overcome environmental obstacles, and face enemies during the adventure.

The project combines gameplay programming, character sprites and animations, 2D physics, health management, and enemy behavior to create an interactive game.

The game is still in development, with one playable map prepared for demonstration.

What It Includes

Gameplay Features

The current project focuses on player controls, combat, enemy interactions, and character systems.

Player Movement

Horizontal movement, jumping, and ground detection to support platforming gameplay.

02

Player attacks, attack combos, and a defending mechanic connected to character animations.

03

Enemy AI

Enemy behavior that includes detecting the player, moving closer, and performing attacks.

04

Health tracking, damage handling, and visual feedback when characters take damage.

Pixel-art characters and animation assets used to bring the knight and enemies to life.

Behind the Scenes

Development Process

The game is developed in stages, from implementing character behavior to testing gameplay interactions.

01

Character Sprites and Animation

Preparing pixel-art characters and connecting animation states to player actions.

02

Gameplay Programming

Using C# scripts to implement movement, jumping, combat, health, and enemy behavior.

03

Enemy Implementation

Configuring enemy detection, movement, attacks, health, and defeat behavior.

04

Testing and Debugging

Testing collisions, animation transitions, damage, and interactions with platforms and objects.

Problem Solving

Challenges and Learnings

Animation Integration

Connecting player input with animation states requires careful timing so movement, attacks, and defense work correctly together.

Physics and Collisions

Platforms, movable objects, and disappearing tiles make it important to test jumping and ground detection in different situations.

Enemy Interactions

Enemy detection, attack ranges, damage, and health need to work together to create consistent gameplay.

Testing and Improvement

Repeated testing helps identify problems and improve how different game systems work together.
