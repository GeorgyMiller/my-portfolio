About the Project

Connecting Residents with Barangay Services

The Barangay Ermita Service Request and Feedback System (BSRFS) is a web application developed to provide residents with a more organized way to communicate their service needs and feedback.

The system provides a resident-facing interface where users can access the available services and submit requests. It aims to make request handling more accessible and reduce dependence on unorganized manual communication.

The project uses PHP for server-side processing and MySQL for database-related functionality.
